# Дизайн-спецификация: Интерактивный Spotlight-онбординг (Часть 1 Jana Academy)

## 1. Обзор и цели
Интерактивный онбординг («Часть 1: Обучение по функционалу платформы» в Jana Academy) заменяет статичные текстовые слайды на интерактивный Spotlight-тур с реальным переходом между рабочими вкладками платформы JanaMen. 

Цели:
- Ознакомить нового сотрудника или руководителя со всеми ключевыми возможностями платформы за 2-3 минуты.
- Динамически подсвечивать реальные элементы управления (Канбан-доска, подача заявок, Jana AI, колокольчик уведомлений, профиль).
- Обеспечить ролевую персонализацию сценариев (для Сотрудника vs для Руководителя).
- Автоматически фиксировать 100% прогресс прохождения Части 1 в профиле сотрудника с праздничной анимацией завершения.

## 2. Архитектура решения

### 2.1 Сервис `OnboardingTourService` (`frontend/src/app/core/services/onboarding-tour.service.ts`)
Служба на базе Angular Signals, предоставляющая централизованное состояние тура:
- `isActive: Signal<boolean>` — статус отображения тура.
- `currentStepIndex: Signal<number>` — порядковый индекс активного шага (0-based).
- `currentStep: Signal<TourStep | null>` — объект метаданных текущего шага.
- `targetRect: Signal<DOMRect | null>` — вычисленные координаты подсвечиваемого элемента (x, y, width, height).
- `steps: Signal<TourStep[]>` — массив шагов для активной роли.

**Интерфейс `TourStep`**:
```typescript
export interface TourStep {
  id: string;
  route: string;
  targetSelector: string;
  titleRu: string;
  titleKz: string;
  descriptionRu: string;
  descriptionKz: string;
  placement: 'top' | 'bottom' | 'left' | 'right' | 'center';
  role?: 'employee' | 'manager' | 'all';
}
```

**Методы сервиса**:
- `startTour(role?: 'employee' | 'manager')`: Инициализирует цепочку шагов для переданной роли и запускает шаг 0.
- `goToStep(index: number)`: Выполняет навигацию `router.navigate([step.route])`, дожидается готовности DOM, находит целевой элемент по селектору `targetSelector`, скроллит к нему `scrollIntoView({ behavior: 'smooth', block: 'center' })` и обновляет `targetRect`.
- `nextStep()`: Переходит на шаг `index + 1`. Если шаг последний, вызывает `completeTour()`.
- `prevStep()`: Переходит на шаг `index - 1`.
- `skipTour()`: Прерывает тур без сохранения завершения.
- `completeTour()`: Завершает тур, отправляет запрос сохранения 100% прогресса для курса платформы в Академии, вызывает поздравление (confetti) и возвращает пользователя на `/academy`.

### 2.2 Компонент `SpotlightTourComponent` (`frontend/src/app/shared/components/spotlight-tour/`)
Глобальный оверлей, подключаемый в `app.html`:
- **Подсветка (Spotlight Overlay)**: Затемненный фон `rgba(15, 23, 42, 0.72)` с вырезанным прямоугольником с закругленными углами вокруг подсвечиваемого элемента (через SVG clipPath или `box-shadow: 0 0 0 9999px rgba(15, 23, 42, 0.72)`).
- **Пульсирующая рамка**: Акцентный контур `--janapost-green` (#00A859) вокруг активного элемента с мягким эффектом свечения.
- **Всплывающая карточка (Tooltip Card)**:
  - Бейдж прогресса: *«Шаг 2 из 6»*.
  - Заголовок и иконка гида.
  - Описание с акцентами.
  - Кнопки управления: «Пропустить», «← Назад», «Далее →» (на финальном шаге — «Завершить онбординг 🎉»).
  - Позиционирование карточки с учетом границ вьюпорта (если элемент у нижнего края — карточка открывается сверху, и наоборот).

## 3. Ролевые сценарии шагов

### 3.1 Сценарий для Сотрудника (`Employee`):
1. **Старт (`/academy`)** — `[data-tour="academy-track-platform"]`:

3. **Действия с задачей (`/tasks`)** — `[data-tour="task-action-btn"]`:
   - Заголовок: *«Быстрые действия»*
   - Описание: *«Нажмите "Начать", чтобы взять задачу в работу. По готовности нажмите "Задача готова", чтобы отправить результат на проверку руководителю.»*
4. **Вкладка «Заявки» (`/requests`)** — `[data-tour="requests-create-btn"]`:
   - Заголовок: *«Кадровые заявки в 2 клика»*
   - Описание: *«Заказывайте справки с места работы, оформляйте отпуска, больничные и авансы без очередей и бумажных заявлений.»*
5. **Вкладка «Jana AI» (`/ai`)** — `[data-tour="ai-chat-input"]`:
   - Заголовок: *«Умный AI-ассистент JanaPost»*
   - Описание: *«Задавайте любые вопросы по Трудовому кодексу РК, внутренним регламентам, льготам и отпускам 24/7.»*
6. **Шапка (`header`)** — `[data-tour="header-actions"]`:
   - Заголовок: *«Уведомления и профиль»*
   - Описание: *«Следите за статусами задач и заявок в центре уведомлений, меняйте язык системы (RU/KZ) и управляйте личными данными.»*
7. **Финал (`/academy`)** — `[data-tour="academy-track-job"]`:
   - Заголовок: *«Онбординг успешно пройден!»*
   - Описание: *«Вы освоили платформу! Часть 1 завершена на 100%. Теперь вы можете перейти к Части 2 — профессиональным курсам по вашей должности.»*

### 3.2 Сценарий для Руководителя (`Manager`):
1. **Старт (`/academy`)** — Приветствие руководителя подразделения.
2. **Задачи отдела (`/tasks`)** — Управление задачами подразделения, распределение исполнителей и кнопка создания задачи.
3. **Согласование задач (`/tasks`)** — Колонка «На проверке», кнопки «Подтвердить» и «На перевыполнение».
4. **Заявки отдела (`/requests`)** — Панель согласования кадровых заявлений сотрудников отдела.
5. **Команда (`/hr/employees`)** — Досье и состав подчиненных сотрудников подразделения.
6. **Jana AI (`/ai`)** — Помощь в составлении служебных записок, отчетов и анализе трудовых нормативов.
7. **Финал (`/academy`)** — Фиксация 100% готовности к управлению процессами в системе.

## 4. Разметка целевых элементов `[data-tour="..."]`

Элементы интерфейса получают уникальные атрибуты:
- `header.component.html`: `data-tour="header-nav"`, `data-tour="header-actions"`.
- `tasks.component.html`: `data-tour="tasks-kanban-board"`, `data-tour="task-action-btn"`, `data-tour="task-review-actions"`.
- `requests.component.html`: `data-tour="requests-create-btn"`, `data-tour="requests-table"`.
- `ai.component.html`: `data-tour="ai-chat-input"`.
- `academy.component.html`: `data-tour="academy-track-platform"`, `data-tour="academy-track-job"`.

## 5. Интеграция с Jana Academy и сохранение прогресса

- В карточке «Часть 1: Функционал платформы» кнопка «Начать обучение» запускает тур `onboardingTourService.startTour()`.
- При завершении шагов тура:
  - Вызывается метод `academyService.completePlatformCourse()` (или обновление прогресса через API / локальное состояние).
  - Прогресс Части 1 устанавливается в `100%`, статус — `'completed'`, оценка — `100%`.
  - Появляется праздничный всплывающий баннер / эффект конфетти.
  - Кнопка в карточке меняется на «Пройти тур повторно» со значком обновления.

---

## 6. Проверка и критерии приемки
1. Тур без сбоев запускается из Jana Academy (Часть 1).
2. Автоматически переходит по страницам (`/tasks` -> `/requests` -> `/ai` -> `/academy`).
3. Подсвечивает нужные элементы и отображает информативные всплывающие карточки.
4. Корректно закрывается по кнопкам «Пропустить» или клавише `Esc`.
5. По завершении фиксирует 100% прогресс Части 1 в интерфейсе Академии.
6. Не вызывает горизонтального или вертикального слома верстки.
